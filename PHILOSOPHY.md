# Philosophy

The framework is built around reusable engineering practices instead of AI-specific prompts.

Core principles:

- Investigate before implementing.
- Evidence over assumptions.
- Small, safe changes.
- Reusable roles over monolithic prompts.
- Playbooks orchestrate roles.
- Skills augment roles.
- Separate methodology from provider capabilities.
- Leave behind enough context for another engineer—or another AI—to continue without rebuilding knowledge.
- Optimize for maintainability rather than prompt cleverness.
