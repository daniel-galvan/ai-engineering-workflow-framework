# Repository Exploration

> Locate and explain relevant source, configuration, tests, entry points, and runtime structure.

## Inputs

* Repository or workspace
* Work-item scope
* Existing work record

## Produces

* Code inventory
* Entry points and data flows
* Build and runtime map
* Relevant tests and configuration
* Current-state facts and unknowns

## Completion Criteria

The relevant behavior can be traced from entry point to observable outcome.

## Safety

Read and verify current files before inferring architecture from names, documentation, or similar repositories.
